**(c)** The SCTP course assumes a POSIX shell (bash or zsh). In your course material, you may encounter commands like these:

```bash
touch notes.txt
export API_KEY=abc123
chmod +x setup.sh
source venv/bin/activate
```

Give **one concrete reason** why running commands like these on Windows PowerShell can fail, even though some commands look similar to PowerShell at first glance. A general-knowledge answer is fine; you do not need to have used PowerShell yourself.

**Answer:**
These commands rely on POSIX/Unix shell syntax and tools (touch, chmod, export, source) that don't exist natively in PowerShell — PowerShell uses its own cmdlets instead (e.g. New-Item instead of touch, $env:VAR = "value" instead of export), and Windows doesn't use the same Unix-style executable permission bit that chmod +x sets, so even similarly-named commands often fail or behave differently.
